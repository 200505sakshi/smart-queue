QwikToken – QR-Based Digital Token System

Skip the Queue. Save Your Time.

QwikToken is a web-based digital token management system designed to reduce waiting time and improve the management of student queues at college administrative offices.

Students can select the service they require and generate a digital token. Staff can call the next token, mark students as served, and monitor the waiting queue through a dashboard.

Problem Statement

Students often spend unnecessary time waiting in queues for college administrative services such as bonafide certificates, fee-related queries, examination forms, and document verification.

QwikToken aims to make this process simpler and more organized through a digital token system.

Features

- Digital Token Generation: Students can enter their names, select a service, and receive a token.
- Multiple Services: Supports bonafide certificates, fee-related queries, examination forms, and document verification.
- Queue Status: Displays the currently serving token, the student's token, and an estimated waiting time.
- Staff Dashboard: Allows staff to call the next student and mark a token as served.
- Waiting List: Displays students waiting for their turn.
- Queue Tracking: Shows the number of waiting and served students.
- Responsive Design: Designed to work on desktop and mobile screens.
- QR Code Access: The published website can be accessed by scanning a QR code linked to its URL.

How It Works

1. The student opens the website.
2. The student enters their name and selects a required service.
3. The system generates a digital token.
4. The token is added to the waiting list.
5. Staff call the next token through the dashboard.
6. Staff mark the token as served when the service is completed.

Getting Started

Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure "index.html", "style.css", and "script.js" are in the same folder.
4. Open "index.html" in a browser or run it using the VS Code Live Server extension.

Access Online

Once deployed using GitHub Pages, open the published website URL or scan its QR code.

Current Limitations

- Queue data is stored in browser memory and resets when the page is refreshed.
- Queue updates are not synchronized across different devices.
- The waiting time is an estimate and may vary depending on the service duration.
- A shared database and backend are not yet implemented.

Future Enhancements

- Backend and database integration for persistent queue data.
- Real-time queue synchronization across student and staff devices.
- Unique QR codes for easier access to the token system.
- Notifications when a student's turn approaches.
- Improved staff authentication and queue analytics.
